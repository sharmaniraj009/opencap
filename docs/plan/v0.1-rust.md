# v0.1: the first working version (Rust only)

Owner order, 2026-11-27: Rust is the main engine, no new Python, open-source drivers first, delete Python
when development is done (ADR-0018). At most two workers at a time, all on the Sonnet model.

## Definition of "working"
A user can install one Rust binary (container, Linux package or Windows installer), point it at a config
directory, poll the PLC families below read-only, and get SubDevice JSON on MQTT with store-and-forward,
a working admin API and web UI, system tags, and an OPC UA server. CI is green with no Python engine.

## Deleting Python
Done when packages 1 to 7 are merged and green:
1. Remove `src/opencap/`, `pyproject.toml`, the Python image and wheel jobs, and Python-only docs.
2. Keep `tests/conformance/` (JSON data) and move whatever Rust still needs from `tests/helpers/` into Rust test crates or an OSS simulator.
3. Remove the pytest-based acceptance suites last, only once their Rust replacements run in CI.
4. One PR per step, CI green on each.
