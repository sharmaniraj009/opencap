Import

A KEPServer project.json export replaces devices.json (as opencap import-kep) and adds stub SubDeviceIds for new devices to devices_map.yaml; your overrides and existing map entries are kept. An opencap export (from Config › Export) restores the files it contains. Every import is a dry run first: nothing is written until you apply it, and the config must not change in between.
